# MangoDB

**Ever wondered what species of mango you're actually eating?**  
Stop guessing — start identifying.

**MangoDB** is a tool for exploring and identifying mango varieties through visual recognition and searchable data.

**Try it live:** [https://mangodb.williamzliu.com](https://mangodb.williamzliu.com)

## What It Does

- Identify mango species from images (WIP or deployed model)
- Browse detailed information on known mango cultivars
- Learn more about regional origins, taste profiles, and seasonality

## Why It Exists

Mangoes come in hundreds of varieties — and most people can’t name more than one. MangoDB helps users, researchers, and hobbyists learn more about the world's most beloved fruit.

Note: If you upload a file that's not a mango, it will assume it's a mango and attempt to guess still.
